Distributed Systems Covers Distributed Systems + Operating Systems + Computer Networks Cloud Computing — UIUC Distributed-systems theory taught through a cloud lens — gossip protocols, consensus, MapReduce, key-value stores; one dedicated Cloud Networking course; lighter coverage of virtualization. About cloud computing. Cloud computing is a hybrid field. It has scientific underpinnings — the distributed-systems theory that makes geo-replicated state work reliably, the networking protocols that route packets across regions, the OS-level virtualization that isolates workloads — and a distinct engineering practice (cloud platforms, deployment, operations). This specialization sits on the scientific side: it draws on theory from Distributed Systems, Computer Networks, and Operating Systems to give you the cloud-relevant subset of each, rather than covering each topic in its full academic depth. For the practitioner side (AWS, IaC, serverless, day-to-day cloud work), see Cloud Engineering in the Engineering Track below.
