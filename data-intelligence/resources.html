Infrastructure Engineering & Operating
The build/operate loop for ML and LLM-based systems — pipelines, registries, deployment, drift monitoring, retraining, evaluation, cost and latency. Infrastructure Engineering and Operating are merged into a single sub-track because in D&I the same engineer designs the infrastructure, ships it, watches it, and fixes it; the build/operate boundary is structural, not functional. The two anchors below — MLOps and LLMOps — cover both halves of that loop.
MLOps
The closed-loop discipline for ML systems: training and feature pipelines, model registries, deployment automation, drift monitoring, retraining cadences, data lineage. Foundational reference is Chip Huyen’s Designing Machine Learning Systems.
Topic Books Courses
ML Systems Design Designing Machine Learning Systems – Chip Huyen Book MLOps Specialization – Duke University Course
LLMOps
The same closed-loop discipline specialised for LLM-based systems: prompt and configuration version management, evaluation harnesses, token-cost and latency monitoring, semantic caching, prompt-injection defense. See also the LLM Engineering Landscape for the full eight-discipline view.
