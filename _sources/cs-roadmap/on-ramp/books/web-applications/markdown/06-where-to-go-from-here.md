# Where to Go from Here

You now know what happens between tapping a button and seeing the result. Here is what to learn next, and what to leave alone for now.

## What to Learn Next

Each step of the trip has its own book in this series:

- The journey between the two sides: *Networking from Zero*.
- The contract and the back end: *APIs to FastAPI*.
- Where the data lives: *Databases from Zero*.
- The tools every developer uses: *Linux and Git from Zero*.
- Getting a back end onto real servers: *Infrastructure Engineering from Zero*.
- Putting it all together: *The Complete Software Engineering Guide*.

For the front end, learn plain HTML, CSS, and JavaScript first, and pick a framework only after that. MDN Web Docs is a free, reliable reference for all three.

## What to Skip for Now

- *Choosing the "best" framework.* They all do the jobs in Chapters 2 and 3. Learn one well.
- *Scaling to millions of users.* Microservices and Kubernetes solve problems you don't have yet.
- *Other ways to talk.* WebSockets, GraphQL, and server-side rendering are variations on the same trip. Meet them when a project needs them.

Whatever you learn next, keep the trip in mind: tap, request, work, response, show. Every new tool is a better way to do one of those steps.
