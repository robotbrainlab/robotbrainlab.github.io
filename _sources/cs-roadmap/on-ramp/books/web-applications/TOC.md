# Web Applications from Zero

**The problem you hit:** I use apps every day, but I have no idea what happens after I tap a button.
**The question it answers:** What happens between tapping a button and seeing the result?
**Target:** 20–25 pages

A short book: it keeps only Understand and What Next.

Title page · Copyright · Contents · Preface (Who This Book Is For, How This Book Is Organized, How to Use This Book, Conventions Used in This Book)

## Part I · Understand

*What to ignore for now:* specific frameworks, how to build a front end or back end, and network protocols in detail.
