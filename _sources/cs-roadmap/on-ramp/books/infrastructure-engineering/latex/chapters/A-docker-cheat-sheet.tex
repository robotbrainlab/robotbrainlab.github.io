\texttt{FROM\ image:tag} & The base image to start from \\
\texttt{WORKDIR\ /app}, \texttt{COPY\ src\ dest} & Set the working folder; copy files into the image \\
\texttt{RUN\ command} & Run a command while building \\
\texttt{ENV\ KEY=value} & Set an environment variable in the image (never a secret) \\
\texttt{USER\ name} & Run as this user instead of root \\
\texttt{EXPOSE\ 8000} & Document the port the app listens on \\
\texttt{HEALTHCHECK\ …\ CMD\ command} & How Docker checks that the app works \\
\texttt{CMD\ {[}"program",}\allowbreak{}\texttt{\ "arg"{]}} & The command a container runs at start \\
