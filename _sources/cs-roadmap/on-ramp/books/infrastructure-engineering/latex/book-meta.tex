  It works on your machine but breaks on the server, and you don't even own a server. This book starts from zero and shows how code gets from your laptop to machines that serve everyone, the same way every time. Every lab runs on your own computer, with no cloud account and no bill.

  \textbf{You'll learn how to:}
  \begin{itemize}
    \item Package an app in a container that runs the same everywhere
    \item Build a pipeline that tests, builds, and deploys on every push
    \item Understand what you rent from a cloud provider, and what it costs
    \item Describe infrastructure in code, and rebuild it in minutes
    \item Roll back safely when a deploy goes wrong
  \end{itemize}}
