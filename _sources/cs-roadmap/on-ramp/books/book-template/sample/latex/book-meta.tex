  Every program reads files, and most of the bugs around them come from one missing idea:

  gives you that idea and a ten-line Python program to put it to work.

  \textbf{You'll learn how to:}
  \begin{itemize}
    \item See the bytes inside any file, and why line endings differ
    \item Read a file correctly in Python and count its words
    \item Read a traceback from the bottom up
