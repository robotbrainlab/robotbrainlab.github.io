# Preface

This sample book exists to exercise every feature of the series template in a few pages. It explains, briefly and truthfully, what a text file is and how to count the words in one with Python. Read it next to its Markdown source to see which convention produces which result.

## Who This Book Is For

You can open a terminal and type a command. You do **not** need to know anything about files, bytes, or Python beyond that. Everything else is explained when it's needed.

## How This Book Is Organized

- **Part I** builds the mental model: what is actually inside a text file.
- **Part II** puts it to use: a ten-line Python program that counts words, and a lab.
- **Appendix A** is a cheat sheet; **Appendix B** is the glossary.

## How to Use This Book

Read the chapters in order; they're short. **Type the code yourself** rather than copying it. Every chapter ends with a lab and a **Summary, Key Terms, and Review Questions** section.

## What You Need Installed

- **Python 3.12 or newer** (check with `python3 --version`)
- **A terminal**: Terminal on macOS, any terminal on Linux, WSL on Windows

## Conventions Used in This Book

- **Bold** marks a new term the first time it is explained. Every such term is also in Appendix B.
- `Constant width` marks code, commands, file names, and anything else you would type exactly.
- Code blocks show Python, shell commands, or program output. Shell commands are shown without a prompt, so you can paste them as they are.
- Three kinds of callout appear in the text:

> **Tip:** A suggestion that saves time or trouble.

> **Note:** A general remark, or something to be aware of.

> **Warning:** A mistake that can cost you data, money, or security. Read these twice.
