# Lab data

One directory per chapter: `data/<chapter-slug>/`.

A lab that needs data ships it here — never "use your own files", because an expected result that
depends on the reader's files holds for nobody. A lab may read this directory and its own fresh
folder, and nothing else.

**Where the book builds its own data, it declares what was planted in it** — every property put
there deliberately — so that no lab can report as a discovery something the data was built to
contain.

Empty. No chapters exist.
