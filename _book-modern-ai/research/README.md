# Research output

One file per area **per run**, written by the scout agent, named `YYYY-MM-DD-<area-slug>.md`. A
cycle normally runs an area once, but **an area reported as too large is run again with a higher
cap** (`../docs/briefs/TEMPLATE-area-research.md`), so a cycle can hold several files for one area.
If two runs of one area fall on one day, suffix the slug `-2`, `-3`.

Research output goes here and **never into a conversation** — that is what keeps the cadence
affordable. **What the scout returns instead is the four sections listed in
`../docs/briefs/TEMPLATE-area-research.md`**, and the records stay in the file.

**No scout has run yet**, so there is no area file here. `frames/` is not empty — it holds the
framing runs and the consolidated candidate list that step 4 rules on.
