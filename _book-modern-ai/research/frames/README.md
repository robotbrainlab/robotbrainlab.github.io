# Framing runs

One file per framing run, named `YYYY-MM-DD-<run-id>.md` — `a` for the first run of a cycle, `b` for
the second. **Two runs per cycle**, so a division that is an artefact of whichever sources one run
opened shows up as a disagreement before the owner rules (`../../docs/briefs/TEMPLATE-area-frame.md`).

They live in their own directory because the scouts' files in `../` are named
`YYYY-MM-DD-<area-slug>.md`, and a framing run's name would be read as an area.
