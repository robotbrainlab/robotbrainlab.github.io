# Return postage labels

A label is emailed when you start a return on an item that qualifies for free return postage. It
is a PDF; print it at any size as long as the barcode is not scaled down.

If you cannot print, ask for a QR code instead. Post Offices and most parcel shops can scan it
and print the label for you.

A label is valid for 21 days from the day it is issued. After that, start the return again and a
new one is sent; the return window itself does not restart.

Clearance items do not get a label, because return postage on clearance is paid by the customer.
Use any tracked service and keep proof of postage.
