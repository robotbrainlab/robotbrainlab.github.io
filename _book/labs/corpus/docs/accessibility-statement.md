# Accessibility

This website aims to meet WCAG 2.2 at level AA. It is tested with a screen reader and by keyboard
only before each release.

Known gaps, which we are working on:

- The delivery-charge table on the Delivery Charges page is not announced correctly by some screen
  readers. The same information is in the text above it.
- The product image gallery cannot be operated by keyboard alone. Each image has a text
  description.
- Two older PDFs are scans and have no text layer. We are retyping them.

If something on the site prevents you ordering, telephone us and we will take the order and apply
any online price.

To report an accessibility problem, email access@harbourlane.example. We reply within two working
days and tell you what we are going to do, including when the answer is nothing.
