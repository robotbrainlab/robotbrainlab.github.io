# My card is closed. Where does the refund go?

A refund goes back to the card that paid. If that card has expired, the refund usually still
reaches the account behind it, because the bank maps the old number to the new one.

If the card has been **closed**, or the account behind it shut, the refund cannot land. We will
issue account credit instead, which is immediate, does not expire, and can be spent on any order.

If you would rather have the money, ask for a bank transfer. We need an account number and sort
code, which we ask for over a secure link rather than by email, and the transfer takes up to 10
working days.

A refund issued as credit never appears on a card statement, which is the commonest reason
somebody thinks a refund has not arrived.
