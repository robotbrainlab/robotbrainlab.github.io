# Resetting your password

Choose **Forgotten password** on the sign-in page and enter the email address on the account. A
reset link arrives within a few minutes and is valid for one hour.

If no email arrives:

- check the spam folder
- check you are using the address the account was opened with, which may not be the one you use now
- check whether the order was placed as a guest, in which case there is no account and no password

We cannot tell you which email address an account uses, and we cannot change the address on an
account from an email asking us to. Both of those are deliberate.
