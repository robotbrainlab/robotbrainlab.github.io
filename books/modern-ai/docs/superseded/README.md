# Superseded documents

**Nothing here is current. Nothing here is input to anything.** Each file carries a dated line
under its title saying what superseded it and why.

**Why these are kept.** `../PROCESS.md` §11.1: nothing is deleted, because a superseded document is
still evidence of what was believed on a date and what it was believed from. **Why they are not in
`../`:** a live directory listing is read by every session before any file is opened, so a void
document sitting in it is read as current — which is `../GOAL.md` §11 class J, and has already cost
this project a re-run.

**Paths inside these files are relative to their old home, `../`.** They were not rewritten: a
dated record of what was cited on a date is falsified by editing it. Add one `../` to resolve one.
