# The check for the consolidation of run g — written BEFORE its output existed

> **SUPERSEDED 2026-11-12.** The check of the run-`g` consolidation, which is void. Kept as a record of what that check found.

**Input:** `research/frames/2026-11-07-g.md`, 283 units plus the labels in its Appendix A.
**The file is not edited before the run.** It is evidence, and a defect found in it is reported, not
patched away.

## A. Arithmetic and completeness

- **Every one of the 283 units gets exactly one verdict.** None unaccounted for.
- **The labels in Appendix A are categories in the file too** and need verdicts. The framing run put
  them in an appendix, which was a decision one stage early; whether this run picks them up is a
  test of whether "every category in every framing file" is read as written.
- Counts close: `AREA` + `DOMAIN` + `RECORD` + `FORMAT` + `PRODUCT` + `UNCLEAR` + merged = the total.

## B. The line this run must not cross

- **No rejection anywhere may rest on importance, size, fashion or being worth covering.** Every
  rejection cites a clause of the rule on kind. **This held last time and must hold again.**
- **No category added that the framing run did not report.**
- Alphabetical. No score, rank or priority.
- Every surviving area tagged with the mode or modes it serves — science, research, engineering.

## C. The fix under test, and the defect that may defeat it

**The fix.** The brief now says: *a record that carries no scope cannot be an `AREA`* — it is
`UNCLEAR`, and what would settle it is a scope statement from the source. Last time, **14 of 69 areas
were given `AREA` on records holding only a name.**

**The defect that may defeat it, found by hand before this run started.** Run `g` writes a one-line
gloss in `INCLUDES` for sources that give a bare label — "product management of AI products" for a
track named *Product Management*, "graph-shaped data and knowledge in AI applications" for a track
named *Graphs*. **I opened the 2026 programme source directly: it is 1.35 MB of session listings
with a `Track:` field and no track descriptions anywhere.** So those scopes are inferred.

**At least 64 of the 283 records are affected** — the 32 tracks of one programme edition, the 18 of
the other, and the 14 categories of the landscape file, all of which are bare labels at source.

**So the pass condition here is a question, not a threshold:**

| | Pass | Fail |
|---|---|---|
| Does this run notice that those `INCLUDES` restate their names? | It flags them — as `UNCLEAR`, or under what it could not settle | It issues `AREA` on them, and the fix has no reach past a framing run that invents scope |

**Either result is worth having.** The run has no sources and no fetches, so if it cannot tell an
invented scope from a real one, that is a structural limit of the design and not a failure of this
run — and it means the defect has to be caught at the framing stage, where it has now been fixed.

By reading the output file against A to E. Counts locate text; they do not settle anything.
