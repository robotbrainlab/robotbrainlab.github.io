# Ledger — what the reader already knows

One row per finished chapter. **Read before writing any chapter**, and grep it for
"Do not" before you write a first paragraph.

**Why this file matters more here than in the finished book.** The language is taught
twice on purpose (decision 15). Part I gets the reader writing Python; Part II returns and
explains it. That makes two questions sharp enough to need a written answer:

- **What did Part I give the reader, and in what words?** Part II must build on exactly
  that, not on a better version of it invented later.
- **What must a Part II chapter NOT re-introduce?** The reader has been using
  comprehensions since chapter 4. Chapter 25 explains what an iterator is; it does not
  teach comprehensions again.
