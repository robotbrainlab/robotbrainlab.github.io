# How to track an order

Sign in and open **Orders**. Each order shows a status and, once it has been dispatched, a
tracking link that opens the carrier's own page.

The statuses mean:

- **Placed** — we have the order and payment is authorised. Nothing has moved yet.
- **Picking** — the warehouse is assembling it. You can still cancel.
- **Dispatched** — it has left us. Cancellation is no longer possible; refuse it at the door or
  return it instead.
- **Out for delivery** — it is on a van today.
- **Delivered** — the carrier has recorded a delivery. If you have not received it, see the
  article on parcels marked delivered that have not arrived.

Tracking updates come from the carrier and not from us, so a tracking page that has not moved for
a day is a question for them. We can see exactly what you can see.

An order placed as a guest has no account to sign into. Use the tracking link in the dispatch
email, or contact us with the order number.
