# How to start a return

Sign in, open **Orders**, choose the order and then **Return an item**. Pick the items and a
reason. You will get:

- a return reference beginning `RET-`
- a postage label, if the item qualifies for free return postage

**Standard items have 30 days from delivery and free return postage. Clearance items have 14 days
and you pay the postage.** The item's page and your order both say which it is.

Pack the item in its original packaging, put the label on the outside, and use any Post Office or
parcel shop. Keep the receipt until your refund appears.

Do not send anything back without a reference. The warehouse cannot match an unreferenced parcel
to an order, and it will sit unprocessed.

Guest orders can start a return from the link in the dispatch email.
