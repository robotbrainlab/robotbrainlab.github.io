Byte & A number from 0 to 255; the unit a disk stores \\
Counter & A dictionary from Python's \texttt{collections} module that counts items \\
Encoding & The rule that maps bytes to characters, such as UTF-8 \\
File & A named sequence of bytes stored on a disk \\
Line & The text between two newline characters \\
Newline & The character that ends a line: \texttt{\textbackslash{}n}, byte
\texttt{0a} \\
pathlib & Python's standard-library module for file paths \\
Text file & A file whose bytes are meant to be read as characters \\
Traceback & The report Python prints when an error stops a program \\
UTF-8 & The dominant text encoding: one to four bytes per character \\
